# paxandchoco.com

Companion site for *The Ultimate Video Game Puzzle Book* by Pax &amp; Choco Publishing.
Static site served by GitHub Pages.

- `/` home, `/secret/` code entry, `/bonus/` reward (encrypted), `/about/`
- `assets/vault.json` is generated by a private build script. The book code is not stored
  anywhere in this repository; only a salted hash and AES-GCM encrypted content.
- Amazon link: set `AMAZON_URL` at the top of `assets/site.js`.
- Fonts: Press Start 2P, Space Mono, VT323 (SIL Open Font License, see `assets/fonts/`).
